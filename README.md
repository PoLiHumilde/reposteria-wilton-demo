# Repostería Wilton · Demo de Edgar

Propuesta independiente de diseño web para Repostería Wilton en Santiago de los Caballeros, República Dominicana. Pendiente de aprobación del negocio.

## Abrir la demo

Abre `index.html` en un navegador. Mantén `hero.jpg`, `cake.jpg` y `cupcakes.jpg` en la misma carpeta. No necesita instalación ni compilación.

## Funciones

- Diseño adaptable a móvil y escritorio.
- Galería de inspiración con filtros.
- Formulario que prepara una consulta por WhatsApp. La persona revisa el mensaje y decide si lo envía.
- Ubicación enlazada a Google Maps y preguntas frecuentes.
